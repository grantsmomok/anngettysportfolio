# Ann Gettys Portfolio

Static website: plain HTML, CSS, and a small amount of inline JavaScript. No build step or dependencies.

## Structure
- `index.html`: main portfolio page (Teaching philosophy, Research, Patient and health education, Multimedia design, Teaching experience). The "View CV" button opens the CV page images in a built-in viewer.
- `teaching-philosophy.html`: full statement of teaching philosophy.
- `spc-*.html`: the SP-C Deficiency online course for families (14 pages, originally built in Canvas). Entry page: `spc-sp-c-deficiency-overview.html`.
- `media/`: all images, videos (MP4), CV page images, and PDF handouts.

## Notes
- All links are relative, so the folder works from any host (for example GitHub Pages) or by opening `index.html` locally.
- Fonts load from Google Fonts (Source Serif 4, Source Sans 3). The site supports light and dark mode.
- Two videos are linked on YouTube rather than hosted: Oxygen Tips and Tricks (https://youtu.be/kMcMAyW8lBg) and the color theory project (https://youtu.be/UnGwqU5yNgg). Both need to be set to Public or Unlisted.
- The chILD Foundation web address is always child-foundation.org (with the hyphen).
